# GitHub + Supabase setup

1. Put the contents of this folder in the GitHub repository root.
2. Use `main` as the deployment branch.
3. GitHub Pages is deployed automatically by `.github/workflows/pages.yml`.
4. Open the app's Settings → Cloud Sync.
5. Create the owner account once, then sign in on other browsers with the same account.

The app contains only the Supabase project URL and publishable browser key. Never add a Supabase service-role/secret key to the repository.
